# Sales Prediction using Machine Learning (CodeAlpha Internship - Task 4)

This repository contains the code and dataset for **Task 4** of the CodeAlpha Data Science Internship. The objective of this project is to build a machine learning regression model to predict future sales based on advertising expenditures across different media channels.

---

## 📊 Project Overview
Advertising budgets across various platforms (TV, Radio, and Newspaper) heavily influence product sales. Using historical advertising data, this project implements a **Linear Regression** model to predict sales and evaluate the effectiveness of advertising investments.

---

## 🛠️ Tech Stack & Libraries
* **Language**: Python
* **Environment**: Jupyter Notebook (`.ipynb`)
* **Libraries**: 
  * `pandas` (Data loading & manipulation)
  * `numpy` (Numerical computations)
  * `matplotlib` (Data visualization & plotting)
  * `scikit-learn` (Machine Learning model training & evaluation)

---

## 📂 Repository Contents
1. **`sales_prediction.ipynb`**: The complete Jupyter Notebook containing data preprocessing, model training, evaluation, and plotting.
2. **`Advertising.csv`**: The dataset containing advertising expenditures and corresponding sales figures.
3. **`sales_actual_vs_predicted.png`**: Visualization plot comparing actual sales versus predicted sales.

---

## 🚀 Model Performance
* **Algorithm**: Linear Regression
* **Evaluation Metrics**:
  * **R² Score**: High accuracy score indicating a strong fit between independent and target variables.
  * **RMSE (Root Mean Squared Error)**: Low error value demonstrating reliable prediction capability.
